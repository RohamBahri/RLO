# Research status · October 2026

MVP5 is the best saved general policy (~6.64% mean *historical reference* gap over n=11,13,15,17,19); the archived means included rare infeasible tours. MBPI reached ~1.1% greedy gap on one n=30 instance after millions of rollouts but has no distribution-level validation. AlphaZero/GVF v3 runs are confounded by instability and uninformative feasibility targets.

**Phase 1:** canonical generator, independent feasible-tour evaluation, fixed data streams, exact n≤12 solution, route-verifiable references, and paired metrics. The archived n=20 OR-Tools costs (means 6.383451, 6.373003 and 6.358619) lack stored tours and used integer/rounded objectives, so are historical only. Freeze stronger n≥20 *route* references using PyVRP or an external solver before tuning; PyVRP 0.14 uses iterated local search, not the older HGS engine.

**Next:** a single masked batched environment and exact cost-to-go from partial states, then zero-training MVP5 sampling and n=10 MBPI diagnostics.

**Research requirements:** See [PRINCIPLES.md](PRINCIPLES.md). Future training must use experience only, on diverse problem instances and settings, with explicit held-out size and parameter shifts. Prior MBPI cross-entropy distillation of search-produced action targets is **not an approved learning objective**. Use rollout returns/advantages in an RL policy-improvement update instead; preserve the historical MBPI implementation only as a diagnostic. Evaluation references and classical heuristics must never become training labels.

**Model/experiments (October 2026):** [docs/spec.md](docs/spec.md) is the fixed CVRP mathematical/observation specification; [PRINCIPLES.md](PRINCIPLES.md) permits KL improvement targets from the agent’s own returns but prohibits external supervision. Experiment entry points are `python -m rlo.train`, `python -m rlo.study` and `python -m rlo.mbpi`. Historical MVP5 uses a different unmasked observation space and remains diagnostic only. Strong large-n reference tours and long converged multi-seed runs are not yet available.

**Group A review corrections (Oct 2026):** Switched to static attention encoder + dynamic decoder, inverse-n sensor, clipped logits, frozen rollout baseline (not self-critical), separate per-size REINFORCE baselines, and full-n POMO starts. Training records transition- and wall-time-based curves; validation uses 256 instances per size by default; frozen baseline promotion does not consume the validation split. Larger PyVRP route references still need to be generated before publication-quality gap claims. The experience-only KL-MBPI update already complies with the current [PRINCIPLES.md](PRINCIPLES.md), since its targets come only from the current policy’s own simulated returns.
